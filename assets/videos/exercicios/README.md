# Demonstrações em vídeo dos exercícios

Nenhum arquivo de vídeo é baixado ou armazenado neste diretório ou no repositório.

O FORJA exibe demonstrações reais dos exercícios por incorporação oficial do YouTube (`youtube-nocookie.com`), configuradas em:

- `assets/js/forja-videos-dados.js` — registro dos vídeos oficiais curtos (até 60s, proporção 16:9 e enquadramento original) para os exercícios da biblioteca.
- `assets/js/forja-videos.js` — resolvedor de prioridade (vídeo do treino personalizado → vídeo oficial → imagem de referência RepDB), player 16:9 com controles e sem reprodução automática, ajuste opcional de zoom e corte 16:9 sem deformação para Shorts verticais em treinos personalizados e seletor **"Procurar vídeo"** no editor de rotinas.
